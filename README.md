## 🚀 Quick Start (Local Run)

This portfolio is completely self-contained in a single HTML file with embedded styles, vector graphics, and scripts.

### Option 1: Direct Run
Double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server
```bash
# Clone the repository
git clone https://github.com/palakpk954/Portfolio_New-Palak.git
cd Portfolio_New-Palak

# Run with Python
python -m http.server 8000
```
Then visit `http://localhost:8000/`.
